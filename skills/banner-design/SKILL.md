# Banner Design

Use this skill when creating banners for social media, advertising, website heroes, or print. Produces multiple art direction variations per request.

## Workflow

### 1. Requirements Gathering

Collect before starting:
- **Purpose**: social post, ad, hero, print
- **Platform & dimensions**: see table below
- **Content**: headline, subheadline, CTA, logo, key visuals
- **Brand guidelines**: colors, fonts, tone
- **Style preferences**: or leave open for recommendations
- **Quantity**: how many variations

### 2. Research

- Activate `ui-ux-pro-max` design intelligence
- Research 2–3 complementary art direction styles
- Select styles that contrast meaningfully (e.g. minimalist vs. bold vs. editorial)

### 3. Design Execution

- Build HTML/CSS at exact platform dimensions (no scaling)
- Generate visual elements:
  - Backgrounds/patterns: fast Standard AI models
  - Hero illustrations: Pro AI models for detail
- Apply safe zone rules (critical content in central 70–80%)
- Maximum 2 typefaces per banner
- Single clear CTA per banner

### 4. Export

- Convert HTML to PNG via screenshot automation at precise dimensions
- Auto-compress files > 1MB
- Name files: `<platform>-<style>-<variant>.png`

### 5. Presentation

- Display all options side-by-side
- Provide rationale for each art direction choice
- List file paths
- Iterate based on feedback

## Design Rules

- **Safe zone**: Keep all critical text and CTAs in the central 70–80% of the canvas
- **CTA**: One per banner — clear, contrasting, action-oriented
- **Typefaces**: Maximum 2 per banner
- **Contrast**: Text must meet 4.5:1 minimum ratio
- **Hierarchy**: Headline → Supporting text → CTA → Logo/brand
