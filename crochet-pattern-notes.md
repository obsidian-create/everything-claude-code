# Häkelmuster-Notizen

## Grundstruktur

**Runde 1:** Kettmaschenkette + drumherum feste Maschen; Ecken = je 3 feste Maschen

**Runde 2+:** Ecken je 3 feste Maschen, Seiten 1:1 (keine Zunahmen)

## Technik

- **Rippeneffekt:** nur hintere Schlinge stechen
- **Höhe:** keine Zunahmen — einfach gerade hochhäkeln
